Set up

  1. In your authenticator app, add an account and choose to enter a key by hand.
  2. Account: admin, key: ABCDEF (time-based). On a phone you can also open it in the app.
  3. Type the code the app now shows, with your password, below.

Nothing is saved until the code checks out, so a mistake here cannot lock you out.
